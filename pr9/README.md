## Завдання 9.2

**Умова:** Напишіть програму, яка виконує команду `cat /etc/shadow` від імені адміністратора, хоча запускається від звичайного користувача. (Ваша програма повинна робити необхідне, виходячи з того, що конфігурація системи дозволяє отримувати адміністративний доступ за допомогою відповідної команди.)

### Опис рішення
Для виконання команди від імені адміністратора використовується утиліта `sudo` (відповідна команда для отримання адмін-доступу в Linux-системах). У програмі застосовується системний виклик `execlp`, який замінює поточний процес на процес `sudo`, передаючи йому аргументи `cat` та `/etc/shadow`. Якщо користувач має відповідні права в конфігурації `sudoers`, система запитає його пароль і виведе вміст захищеного файлу.

### Код програми (task9_2.c)

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

int main(void) {
    execlp("sudo", "sudo", "cat", "/etc/shadow", NULL);
    perror("Execution failed");
    return EXIT_FAILURE;
}
```

### Компіляція та запуск

Скомпілюй програму і запусти. Вона попросить твій пароль від Ubuntu (оскільки викликається `sudo`), після чого виведе вміст файлу `shadow`:

Висновок
Під час виконання завдання було досліджено можливість обходу обмежень прав доступу за допомогою виклику зовнішніх інтерпретаторів або утиліт підвищення привілеїв. Використання системного виклику `execlp` дозволило інтегрувати системну команду `sudo` у власну програму для доступу до захищених файлів ядра, таких як `/etc/shadow`, за умови наявності відповідних прав у конфігурації системи.
